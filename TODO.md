# Словарь: заявки на карточки

Список для владельца проекта. Добавляйте слова в раздел «Ожидают» — по одному в строке,
достаточно самого слова. Всё после `—` читается как пожелание к карточке.

Когда карточка готова, строка переезжает в «Готово» со ссылкой и датой.
Этот файл правится только вручную; скрипты его не трогают.

Текущая версия формата карточки: **2** (три примера на каждую форму, этимология,
подсказка для запоминания, идиомы). Статус всех слов — в `data/ranked.json`,
поле `format`.
