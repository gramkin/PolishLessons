# Phase 10 — «Итоги B2» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a `write` quiz question for open writing, a B2 test in the state-certificate shape
(chapter 37) and placement questions for chapters 30–36.

**Architecture:** `write` joins the zod `questionSchema` union, so the validator, the stored
mistakes and `Quiz.vue` all see it. Its verdict comes from a pure `writeVerdict` in
`app/utils/quiz.ts`; a new `QuizWrite.vue` collects the text and the self-check. It is never
stored as a mistake. The rest is content.

**Tech Stack:** Nuxt 4, Vue SFC, zod, Vitest (unit + nuxt projects).

**Spec:** `docs/superpowers/specs/2026-10-11-path-to-b2-design.md` (section «Phase 10»).

## Global Constraints

- TDD for code: a failing test first, then the change.
- `app/` imports runtime values from `#shared/...`; `app/utils` stays free of Nuxt imports.
- Content: `<!-- review -->` / `# review`; a reviewer agent reads it; validate, lexicon and
  prettier pass.
- Commits through `git commit -F <file>`, ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Verdict of a `write` question** (fixed here): every checklist point ticked → `correct`; at
least three quarters → `almost` (counted as right by `scoreQuiz`, shown as «Почти»); fewer →
`wrong`. The spec's «share of ticked points» is approximated this way because a quiz scores
whole questions.

// app/utils/quiz.ts
/** A writing task is judged by the learner against a checklist: all of it, most of it, or not. */
export function writeVerdict(ticked: number, total: number): Verdict {
  if (total > 0 && ticked >= total) return 'correct'
  return total > 0 && ticked / total >= 0.75 ? 'almost' : 'wrong'
}
